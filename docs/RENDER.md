# Deploy on Render

This repo ships a [Render Blueprint](https://render.com/docs/blueprint-spec) (`render.yaml`) with:

| Service | Name | Description |
|---------|------|-------------|
| PostgreSQL | `pawankalyanfan-db` | Database (or use [Neon](https://neon.tech) instead) |
| Web (Docker) | `pawankalyanfan-api` | API gateway + all microservices |
| Web (Node) | `pawankalyanfan-web` | Next.js frontend |

## Quick deploy

1. Push this repo to GitHub.
2. [Render Dashboard](https://dashboard.render.com) → **New** → **Blueprint**.
3. Connect the repository and apply `render.yaml`.
4. After the API service is live, open **Shell** on `pawankalyanfan-api` (or run locally against prod `DATABASE_URL`):

   ```bash
   npm run db:seed
   ```

5. Open the `pawankalyanfan-web` URL (e.g. `https://pawankalyanfan-web.onrender.com`).

## Environment variables

Set in the Render dashboard after deploy:

### `pawankalyanfan-api`

| Variable | Required | Notes |
|----------|----------|--------|
| `DATABASE_URL` | Yes | From Render Postgres or Neon (pooled) |
| `DIRECT_URL` | Yes | Neon direct URL; for Render Postgres use same as `DATABASE_URL` |
| `JWT_SECRET` | Yes | Auto-generated by blueprint |
| `OPENROUTER_API_KEY` | No | AI chat |
| `RAZORPAY_*` | No | Payments |

### `pawankalyanfan-web`

| Variable | Required | Notes |
|----------|----------|--------|
| `NEXT_PUBLIC_API_URL` | Yes | Use `/api` (proxied to gateway) |
| `API_GATEWAY_HOST` | Yes | Set automatically from `pawankalyanfan-api` host |
| `WEB_HOST` | Yes | This service’s `*.onrender.com` hostname |
| `NEXT_PUBLIC_SITE_URL` | Yes | `https://<your-web-host>.onrender.com` |

Update `NEXT_PUBLIC_SITE_URL` in the dashboard if Render assigns a different hostname than the blueprint default.

## Using Neon instead of Render Postgres

1. Remove or skip the `databases` block in `render.yaml`.
2. On `pawankalyanfan-api`, set:
   - `DATABASE_URL` — pooled Neon URL
   - `DIRECT_URL` — direct Neon URL (for Prisma)

## Local production-like test

```bash
# Terminal 1 — API stack (Docker)
docker build -f Dockerfile.backend -t pkf-api .
docker run --rm -p 4000:4000 --env-file .env -e PORT=4000 pkf-api

# Terminal 2 — Web
cd apps/web
set NEXT_PUBLIC_API_URL=/api
set API_GATEWAY_URL=http://localhost:4000
npm run build && npm run start
```

## Health checks

- API: `GET https://<api-host>/api/health`
- Web: `GET https://<web-host>/`

## Notes

- Free/starter instances **spin down** after inactivity; first load may take 30–60s.
- The API runs all microservices in one container to reduce cost (see `Dockerfile.backend`).
- Wallpaper images are served from `apps/web/public` (included in the web build).
